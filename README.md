# My Budget Tracker

## Project Description

My Budget Tracker is a simple web application designed to help users track and organize their expenses.

For Week 3, I focused on improving the visual design of the existing Budget Tracker using CSS. I improved the colors, typography, expense table, Add Expense form, spacing, borders, and overall appearance.

## Technologies Used

* HTML5
* CSS3
* Google Fonts

## Visual Design

### Color Palette

I used a consistent color palette throughout the application.

* Blue for headings and table headers
* Green for the Add Expense button
* Light background for the page
* White for the content cards

### Typography

I used Google Fonts to improve readability and visual hierarchy.

* Poppins for headings, labels, buttons, and table headings
* Roboto for body text and table content

### Add Expense Form

The form includes:

* Expense name input
* Amount input
* Category dropdown
* Add Expense button

CSS was used to add spacing, borders, padding, and rounded corners to the form elements.

### Expense Table

The expense table includes:

* Styled table header
* Borders
* Padding inside cells
* Alternating row colors
* Consistent typography
* Clear spacing

### CSS Box Model

I used the CSS Box Model to organize the page.

The project uses:

* **Margin** to separate sections
* **Padding** to create space inside containers
* **Borders** to define different areas
* **Border-radius** to create rounded corners

The page heading, Add Expense form, and Expense Table are presented as separate visual cards.
